구글 시트 연동 정밀 진단 및 해결 가이드

현재 구글 시트와 웹앱 간의 실시간 통신 상태 분석

1. 웹앱 API 서버 통신 정상 (HTTP 200)

Google Apps Script 웹앱 URL이 올바르게 배포되어 있으며 클라이언트와 정상적으로 통신하고 있습니다.

2. 스프레드시트 탭 조회 주의 필요

시트에서 null (reading getDataRange) 오류가 발생하거나 0건을 반환합니다.

"연결이 안 되는 것처럼 느껴지는" 정확한 원인

  1. 시트 탭(Sheet Tab) 이름 불일치:
    Apps Script 코드 상에서 getSheetByName("도서") 또는 getSheetByName("Books") 처럼 특정 탭 이름을 찾고 있으나, 구글 스프레드시트의 탭 이름이 '시트1' 또는 다른 이름으로 되어 있어 시트를 찾지 못하고 있습니다.
  2. 예약 저장 시트 부재:
    예약 신청 시 기록될 "예약" (또는 "Reservations") 시트 탭이 생성되어 있지 않아 TypeError: Cannot read properties of null (reading 'getDataRange') 에러가 발생합니다.

가장 쉬운 해결책: 자동 복구 지원 Apps Script 코드 (.gs)

아래 코드는 스프레드시트에 도서 및 예약 탭이 없으면 자동으로 탭과 기본 헤더를 생성하고 초기 샘플 도서까지 등록해주어 null 오류를 원천 방지합니다.

구글 스프레드시트 적용 3단계 순서

  1. 도서관용 구글 스프레드시트 열기 → 상단 메뉴 [확장 프로그램] > [Apps Script] 클릭
  2. 기존 코드를 모두 지우고 위의 [전체 코드 복사] 내용을 붙여넣기 후 저장 (Ctrl+S)
  3. 우측 상단 [배포] > [새 배포] 클릭 → 유형: 웹 앱 → 액세스 권한: '모든 사용자(Anyone)'로 설정 후 배포!
URL을 새로 배포한 경우 [API 연동 설정]에서 갱신할 수 있습니다.

Google Apps Script 연동 설정

Google Apps Script에서 새 배포를 진행한 경우 새 웹앱 URL(/exec)을 입력하세요.

연동 엔드포인트 명세:
GET ?action=getBooks
POST { action: "createReservation", bookId, userName, userEmail }
GET ?action=getReservations&email={email}
POST { action: "cancelReservation", reservationId }
